# 毕业季校园影像征集

证据模式：live；方案 ID：plan-b18b897f1b0625e09007

## 目标

通过校园公众号发布毕业季校园影像征集内容，向毕业生说明可提交校园照片或不超过30秒的回忆短片，并引导关注校园公众号后续推文获取投稿入口与截止时间。

## 受众

本校毕业生及校园公众号读者。

## 核心信息

毕业季校园影像征集：毕业生可提交校园照片或不超过30秒的回忆短片；投稿须取得被摄者同意，作品由运营初审后展示；评选方式为主题契合度与表达完整度，不承诺流量奖励；投稿入口、截止时间与展示安排以校园公众号后续推文为准。

## 排期

仅安排校园公众号的脚本与图文内容准备及后续推文节奏；具体发布日期、投稿开放时间、初审与展示排期待运营确认，不虚构日期或入口。

## 执行角色

内容运营：确认投稿入口、截止时间、初审与展示排期，审核脚本与图文；校园公众号编辑：按确认后排期发布；评审：按主题契合度与表达完整度执行。

## 建议指标

建议指标（非承诺，仅供参考）：校园公众号推文阅读量、有效投稿数量、初审通过作品数量、投稿入口相关咨询量；不设流量奖励承诺。

渠道：校园公众号
