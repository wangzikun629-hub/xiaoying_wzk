# 毕业季校园影像征集

证据模式：live；方案 ID：plan-b18b897f1b0625e09007

## 目标

以校园公众号为唯一渠道，征集毕业生提交的校园照片与不超过30秒的回忆短片，形成可用于后续展示的毕业季影像内容池；按 campus-02 规则取得被摄者同意、由运营初审后展示，不承诺流量奖励。

## 受众

本校毕业生（投稿人）；关注毕业季内容的校园公众号读者及出镜同学。

## 核心信息

毕业季校园影像征集｜用校园照片和不超过30秒的短片留住校园回忆。毕业生可提交校园照片和不超过30秒的回忆短片，参与毕业季影像征集；投稿须取得被摄者同意，作品由运营初审后展示；评选关注主题契合度与表达完整度，不承诺流量奖励。投稿入口、投稿截止时间与展示安排尚未确认，以校园公众号正式推送为准。

## 排期

相对排期（绝对日期待运营确认，全部工作须在 2030-06-01T05:00:00+00:00 截止时间前完成）：D-2 视频脚本定稿，确认画面版权与肖像授权，分镜2 画面标注“示意，非真实投稿入口”；D-1 公众号图文定稿，并补齐投稿入口路径、投稿截止时间、展示安排、初审反馈时限与结果通知方式、评选结果公布方式、肖像授权声明模板；D0 校园公众号推送图文，视频随该次推送发布（不作为其他平台投放内容）；D0 起运营按初审结果安排展示。投稿截止与展示时间属待确认项，不预设具体日期。

## 执行角色

内容运营：负责视频脚本与图文文案定稿及口径统一；初审运营：负责投稿作品初审、合规（肖像授权）核验与展示排序；校园公众号发布负责人：负责推送排期、投稿入口配置与结果通知。

## 建议指标

建议指标（均为观测建议，不构成流量或转化承诺）：校园公众号图文阅读量、投稿参与者人数、有效投稿作品数、含明确肖像授权的合规投稿占比、初审通过率、实际展示作品数量。
