# 毕业季校园影像征集

证据模式：live；方案 ID：plan-b18b897f1b0625e09007

## 目标

在毕业季发起校园影像征集，收集毕业生提交的校园照片与不超过30秒的回忆短片，经运营初审后在校园公众号与短视频平台展示。

## 受众

应届毕业生及校园在校学生（素材未提供更细人群画像，细分人群待运营确认）。

## 核心信息

毕业前把舍不得删的校园画面留下来：投稿校园照片或不超过30秒回忆短片即可参与；投稿须取得被摄者同意，作品由运营初审后展示，评选看主题契合度与表达完整度，不承诺流量奖励。

## 排期

相对排期：T0 完成视频脚本与图文文案（报价预计 T0+60 分钟，约 03:05 完成）；T0+1 提交运营审核授权与初审口径；T0+2 起在校园公众号、短视频平台发布征集内容并开放投稿入口；征集截止、展示排期与评选公布时间待运营确认后对外发布。所有绝对日期不虚构，以运营确认的投稿入口与截止时间为准。

## 执行角色

运营：负责素材初审、展示排布与线上发布，并确认投稿入口、截止时间与评选时间；投稿毕业生：提交校园照片或不超过30秒回忆短片，并取得被摄者同意；渠道运营：维护校园公众号与短视频平台的发布与话题呈现。

## 建议指标

以下均为建议指标，非承诺值：建议关注投稿数量、有效授权作品占比、初审通过率、校园公众号阅读量与短视频平台播放完成情况、话题参与数；素材未提供历史基线，目标数值待运营确认。

渠道：校园公众号、短视频平台
