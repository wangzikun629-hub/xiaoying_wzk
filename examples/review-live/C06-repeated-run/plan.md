# 毕业季校园影像征集

证据模式：live；方案 ID：plan-b18b897f1b0625e09007

## 目标

在预算 10、截止 2030-06-01T05:00 的约束下，通过校园公众号发起毕业季校园影像征集，收集毕业生提交的校园照片与不超过30秒的回忆短片，并沉淀可用于毕业季内容展示的影像素材（本方案仅覆盖校园公众号一个渠道）。

## 受众

本校应届毕业生，以及在校园公众号阅读毕业季内容的在校生；提交者需确保投稿影像已取得被摄者同意。

## 核心信息

核心信息：毕业季校园影像征集面向毕业生，可提交校园照片或不超过30秒的回忆短片；投稿须取得被摄者同意，作品由运营初审后展示；评选依据主题契合度与表达完整度，不承诺流量奖励。投稿入口、投稿截止时间与展示安排以运营后续在校园公众号的正式通知为准。

## 排期

相对排期（T0 = 报价预计完成时间 2030-06-01T03:05，活动截止 2030-06-01T05:00）：T0 视频脚本与图文文案完成；T0 起 30 分钟内运营补齐投稿入口、投稿截止时间、展示安排三项占位信息，并复核同意与初审规则表述；T0+1 小时在校园公众号发布图文文案，同篇配合按视频脚本拍摄的征集短片；发布后至截止时间前仅在校园公众号推送内维护投稿说明与初审进度。排期只覆盖校园公众号，不安排其他渠道的内容分发、转发或投放。

## 执行角色

运营（校园公众号）：发布图文与短片、补齐投稿入口/截止时间/展示安排、执行作品初审与展示；内容生成：由 primary 后端生成视频脚本与图文文案（已完成，各 4，合计 8）；拍摄剪辑：按视频脚本分镜执行，画面优先使用空镜或示意素材，使用真实毕业生影像须取得被摄者同意；统筹：核对预算与截止时间，确认占位信息补齐后再对外推送。

## 建议指标

以下均为建议指标，非承诺结果：建议观察校园公众号图文阅读量、投稿作品数量、符合被摄者同意规则的作品占比、运营初审通过作品数、按主题契合度与表达完整度评估的作品分布；不设置流量或转化承诺。
