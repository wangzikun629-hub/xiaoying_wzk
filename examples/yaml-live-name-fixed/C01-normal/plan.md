# 毕业季校园影像征集

证据模式：live；方案 ID：plan-7f0e79f089efce38e567

## 目标

以「毕业季校园影像征集」为主题，面向毕业生征集校园照片与不超过30秒的回忆短片，为校园公众号与短视频平台产出可发布的视频脚本、图文文案及两渠道改写版本。目标聚焦征集与合规展示流程（投稿须取得被摄者同意，作品由运营初审后展示），不承诺流量、转化或参与人数。依据素材 campus-01、campus-02。

## 受众

应届毕业生为主的在校学生群体，即素材描述中可提交校园照片与不超过30秒回忆短片的毕业生；同时覆盖校园公众号读者与短视频平台校园内容受众。

## 核心信息
