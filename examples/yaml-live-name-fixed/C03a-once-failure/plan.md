# 毕业季校园影像征集

证据模式：live；方案 ID：plan-c7e02bb1a208a63bcb5f

## 目标

在校园公众号发布毕业季校园影像征集推文（图文 + 按脚本制作的短片），向毕业生完整说明征集内容与规则，为后续正式投稿做认知铺垫；不承诺流量、奖励或参与转化。

## 受众

校园公众号关注者中的应届毕业生。

## 核心信息

毕业生可提交校园照片，或不超过30秒的回忆短片，参与毕业季校园影像征集；投稿须取得被摄者同意，作品由运营初审后展示；评选参考主题契合度与表达完整度，不承诺流量奖励；投稿方式、展示安排与截止时间待运营确认。

## 排期

待运营确认发布日与投稿入口后，在校园公众号推送 1 条图文并嵌入按脚本制作的短片；推送前完成运营初审，并补齐投稿方式、展示安排与截止时间信息。具体发布日期、时段与投稿截止时间待运营确认。

## 执行角色

内容运营：公众号图文撰写、排版与投稿信息补齐；运营审核：投稿作品初审及发布内容合规确认；视频制作：按脚本完成短片（全片及各分镜时长待制作与运营确认，投稿短片时长不超过30秒）。

## 建议指标

以下均为建议监测指标，不设目标值，也不构成流量或转化承诺：公众号图文阅读量（建议）；点赞与在看数（建议）；分享次数（建议）；留言及私信咨询数（建议）；投稿提交数量（建议）；投稿合规率，即取得被摄者同意的比例（建议）；作品初审通过数量（建议）。
