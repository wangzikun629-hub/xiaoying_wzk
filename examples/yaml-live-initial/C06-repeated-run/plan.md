# 毕业季校园影像征集

证据模式：live；方案 ID：plan-b18b897f1b0625e09007

## 目标

在校园公众号开展毕业季校园影像征集，面向毕业生收集校园照片和不超过30秒的回忆短片，经运营初审后展示；具体发布、投稿入口与展示排期待运营确认。

## 受众

毕业生；投稿者须取得被摄者同意。

## 核心信息

毕业季校园影像征集：毕业生可提交校园照片或不超过30秒的回忆短片；投稿须取得被摄者同意，作品经运营初审后展示；评选关注主题契合度与表达完整度，不承诺流量奖励；投稿入口、截稿时间与展示安排以校园公众号正式通知为准。

## 排期

仅安排校园公众号：发布前由运营确认投稿入口、截稿时间、展示排期并完成内容校对；发布后按确认的排期进行初审与展示；不安排其他渠道转发或投放。

## 执行角色

校园公众号运营：确认投稿入口、截稿时间、展示排期，执行初审与展示；内容编辑：校对视频脚本和图文文案；投稿者：按规则取得被摄者同意。

## 建议指标

建议指标（仅建议监测，不承诺结果）：公众号图文阅读量、规则咨询次数、有效投稿数、初审通过数、展示作品数、被摄者同意说明完整率。

渠道：校园公众号
