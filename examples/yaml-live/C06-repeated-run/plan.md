# 毕业季校园影像征集

证据模式：live；方案 ID：plan-b18b897f1b0625e09007

## 目标

面向毕业生征集毕业季校园影像（校园照片与不超过30秒的回忆短片），投稿须取得被摄者同意，作品经运营初审后在校园公众号展示；评选依据为主题契合度与表达完整度，不承诺流量奖励或评选结果。

## 受众

主要受众为毕业生（投稿人）；次要受众为校园公众号读者（作品展示对象）。投稿涉及他人肖像时，由投稿人负责取得被摄者同意（依据 campus-02）。

## 核心信息

毕业季校园影像征集：毕业生可提交校园照片，以及不超过30秒的回忆短片；投稿须取得被摄者同意；作品由运营初审后展示；评选依据为主题契合度与表达完整度；不承诺流量奖励。发布与投稿入口以校园公众号推文为准。

## 排期

相对排期（仅校园公众号，具体日期均待运营确认）：第1步内容定稿（视频脚本与图文文案已完成）；第2步运营确认投稿入口、征集截止时间、展示排期、结果公布时间，以及投稿数量与格式要求；第3步校园公众号推文发布并开启征集；第4步运营初审来稿；第5步校园公众号展示初审通过的作品。

## 执行角色

内容策划与脚本撰写：已完成视频脚本（result_id 9c96889d-ba6f-4d35-b9d7-20a15ee7c568）与图文文案（result_id 6ad7d8cc-d90d-42e1-a15f-7587a0430e2d）；校园公众号运营：确认投稿入口与规则、执行初审、发布推文与展示作品；视觉设计：配图与封面，画面为示意，需使用自有或已获授权素材，建议总时长、画幅、字幕安全区与可商用配乐由运营确认；投稿人：自行完成被摄者同意确认。

## 建议指标

以下均为建议指标，非承诺值：校园公众号推文阅读量、投稿数量、含被摄者同意的合规投稿占比、运营初审通过率、校园公众号展示作品篇数。不设置流量奖励、转化率或涨粉承诺类指标。
