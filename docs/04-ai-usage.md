# AI 使用与贡献记录

本项目允许AI辅助。以下按本次会话实际工作记录，不能作为候选人已经独立完成的声明。

AI辅助范围：阅读用户题面、检索并核对官方示例；形成及修订规划；生成当前Python代码、测试、合成数据、CLI、文档和评估脚本；执行依赖安装、运行测试与Mock场景；根据真实错误修复代码。当前代码主要由AI在本地工作区实现。

用户已经贡献：提供原始考核要求，选择内容任务规划题，指定Deep Agents和Content Builder参考项目；要求以完整验收为目标而非严格三小时；要求重复复核需求；选择OpenAI兼容模型接入方式。

候选人亲自修改的代码、独立发现的问题、亲自执行的测试与阅读理解：**尚未提供，需要候选人据实补充。** 不将AI执行命令写成候选人独立验证。模型账户与密钥由用户本地配置，AI记录不得含密钥值。

AI辅助验证：实际运行pytest、Mock场景生成器和代码检查，结果引用examples。真实模型验证目前待接口配置；Mock策略按观察作确定性分支，不证明真实模型决策。

本轮验证结果：当前41项测试通过，独立虚拟环境复验通过，17个Mock子场景通过，交付链接审计通过。OpenAI兼容适配器另有无网络HTTP协议测试；它验证消息/工具/脚本子调用接线，不是模型能力实验。

建议个人补充记录格式：日期/实际用时、文件与修改点、修改原因、修改前失败表现、本人运行命令与实际结果、仍不理解或未验证的部分。面试前至少能说明费用账目、为什么需要重新估算、失败与部分成功如何保留、幂等及续跑边界，并亲自复现关键场景。
